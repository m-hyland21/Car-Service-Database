# Car Service Database (SQL)

## Project Overview

A relational car service database developed as part of university coursework at Ulster University. The project uses SQL to organise and manage information about customers, vehicles, employees and car servicing.

## Technologies Used

- SQL
- MySQL
- Relational database design
- Primary and foreign keys
- Stored procedures and triggers

## Features

- Stores customer and vehicle information
- Records car service bookings and maintenance details
- Manages employee information and service assignments
- Uses relational tables and constraints to maintain data integrity
- Includes SQL queries to retrieve service information
- Uses a stored procedure to add service bookings
- Includes a trigger to automate service-related data processing

## Database Structure

The database includes tables for customers, cars, services, employees and their relationships.

Primary and foreign keys are used to connect related records and maintain referential integrity.

## SQL Files

- `CreateCarServiceDatabase.sql` — Creates the database
- `CreateTableSQLCode.sql` — Defines the tables and relationships
- `InsertIntoCustomerTableSQL.sql` — Inserts customer records
- `InsertIntoCarTableSQL.sql` — Inserts vehicle records
- `InsertIntoEmployeeTableSQL.sql` — Inserts employee records
- `InsertIntoServiceTableSQL.sql` — Inserts service records
- `InsertIntoWorks_onTableSQL.sql` — Inserts employee-service relationships
- `StoredProcedureandTrigger.sql` — Implements a stored procedure and trigger
- `BQ1.sql` and `BQ5P2.sql` — Example database queries

## Skills Demonstrated

SQL programming, database design, relational modelling, data integrity, query writing and problem-solving.

## Project Context

Developed as part of the COM106 database coursework at Ulster University.
